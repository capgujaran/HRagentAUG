# PeopleFlow HR

A self-contained HR dashboard built with Java and CSS. No framework or external dependencies are required.

## Run

```powershell
.\run.ps1
```

Then open <http://localhost:8080>.

## Features

- Employee directory with live search and department filters
- Add-employee workflow backed by a Java API
- Leave request approvals and rejections
- Onboarding task tracking
- Responsive, accessible UI
- In-memory sample data that resets when the server restarts
